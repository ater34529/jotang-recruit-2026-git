# task02
1.核心是‌执行权限的差异‌：  
+ 普通聊天AI仅具备纯文本生成能力，没有对接外部文件系统、代码编辑的操作通道，输出内容只能停留在对话界面  
+ Agent额外封装了可被模型调度的工具执行层，能直接将生成的操作指令落地为读写文件、修改代码的实际动作。

2.Tool是Agent突破纯文本限制的核心载体，一方面扩展大模型的能力边界，弥补其知识截止、算力不足的短板；另一方面将抽象规划转化为可落地的执行动作，同时把执行结果回传给模型，形成“规划-执行-修正”的完整闭环。

3.本质是给Agent划定明确的行为边界：对齐项目的业务目标与输出规范，避免模型自由发散做出不符合预期的操作；提前明确禁止项，从源头降低安全风险；统一协作标准，减少不必要的重复询问，提升多轮任务的执行一致性。

4.“忘事”核心是上下文窗口溢出，长任务下早期历史内容被挤出模型的单次处理上限，也可能是历史内容的检索召回失效，导致模型无法获取对应信息。
额度主流按全链路Token消耗计算，覆盖输入提示词、模型输出、工具返回结果的全部文本量，部分平台也会按工具调用次数、工作流执行步骤单独折算。

5.会直接失去所有安全约束：攻击者可通过提示词注入诱导Agent执行恶意指令，造成敏感数据泄露、全量文件被删除、系统被完全接管的严重后果。
